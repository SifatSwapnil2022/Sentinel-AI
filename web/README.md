# Sentinel dashboard

React and TypeScript front end for Sentinel. It reads the same JSON shapes the API will serve;
until then it uses demo data generated by running synthetic traffic through `sentinel_core`
(`make fixtures` at the repository root).

Design decisions and tokens: [DESIGN.md](DESIGN.md).

```bash
npm ci
npm run dev        # http://localhost:5173
npm run check      # types, lint, unit and component tests
npm run e2e        # browser tests and accessibility scans (builds first)
```

`npm run e2e` downloads Playwright's Chromium the first time (`npx playwright install chromium`).
If that download is blocked, set `CHROMIUM_PATH` to any local Chromium binary.
`node scripts/screenshots.mjs <dir>` captures every page at desktop and phone sizes in light and
dark mode, for visual review.

## Structure

| Path | What it holds |
| --- | --- |
| `src/data` | Zod schemas for every payload, and query hooks that validate responses |
| `src/lib` | Formatting and the plain-English summaries, as pure functions |
| `src/components` | Status marks, the range glyph, legends, load and error states |
| `src/charts` | Hand-built SVG charts on d3 scales: accuracy, label check, drift, bridge |
| `src/pages` | One file per route |
| `e2e` | Playwright journeys, keyboard access, layout and axe accessibility checks |
